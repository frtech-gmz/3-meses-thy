# 3 meses com Thy

Um presente digital delicado, romântico e responsivo para celebrar 3 meses de namoro.

## Como abrir o projeto localmente

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no seu computador.
3. Dê dois cliques em `index.html` para visualizar o site no navegador.

## Publicação no GitHub Pages

1. Acesse https://github.com e faça login na sua conta.
2. Crie um novo repositório ou use este que já foi configurado.
3. Faça upload dos arquivos do projeto para a raiz do repositório.
4. Vá em `Settings` → `Pages`.
5. Em `Build and deployment`, escolha:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Salve.
7. Aguarde alguns instantes até o GitHub gerar a URL pública.
8. Copie a URL publicada e compartilhe com sua namorada.

## Personalização rápida

Para trocar as imagens futuras, substitua os placeholders na seção de galeria em `index.html`:

- "Nossa história"
- "Meu momento favorito"
- "Nós dois"

Você pode substituir cada card pela imagem real, mantendo a estrutura atual do layout.

## Observações

- O site funciona sem música.
- O botão de música usa áudio gerado localmente, sem direitos autorais.
- O layout é responsivo e compatível com celular e desktop.
